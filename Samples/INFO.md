# Samples #

Samples to use for the sidechain feature may be found here.
One of the coolest features of Shaver is the ability to load samples, whether one shots, loops, or audio clips up to 30s in length, which can then be used as a sidechain input for the OSC ENV, FILTER, or both.
Additional controls provide flexibility in use of arbitrary inputs to duck or increase the amplitude or filter frequency of an oscillator. This can be used in conjuntion with an LFO, set for retrigger or free repeat, and you have a threshold and gain control, providing truly unique and interesting sound shaping.
I have never seen this feature implemented this way, especially not in an additive type synth!
